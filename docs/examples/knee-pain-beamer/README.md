# Beamer 医学文献汇报示例

**膝骨关节炎：用疼痛重新审视影像分级**

由医学文献汇报 PPT Skill v1.0 工作流生成，采用 Beamer Metropolis 风格原生 PowerPoint 模板。整套 17 页，方法部分为第 4–10 页，共 7 页；建议讲述时间约 20.5 分钟，其中方法约 11.1 分钟，占 54.1%。

[在线审阅](https://acrobat-bit.github.io/medical-literature-ppt-skill/examples/knee-pain-beamer/) · [下载 PPT](deck.pptx?raw=1) · [逐页讲稿](notes.md) · [PDF 预览](preview.pdf) · [讲述重点](focus-plan.txt)

## 使用

在线审阅支持逐页导航、讲稿、来源、原图放大、修改意见与感想填写。意见保存在当前浏览器，可通过 JSON 或 Markdown 导出。

下载完整离线包后解压，打开 `index.html` 即可使用。请保留文件夹内的 `slides` 和下载文件。

## 内容顺序

封面 → 作者简介 → 背景 → 方法（研究流程、学习目标、联合训练、差异量化、评分对齐、等量数据消融、信号来源检验）→ 结果 → 讨论 → 亮点 → 局限 → 感想。

PPT 的标题、正文和备注可编辑；科学图表使用原文 PDF 提取的图片。网页中的 17 张预览由这份 PPTX 实际渲染生成，保留 3840 × 2160 像素。
