# 文章亮点与讲述重点

先判断文章最值得讲的内容，再分配正文篇幅、图表位置和讲稿时间。通读引言、方法、结果、讨论及原图后，从选题、方法、结论讨论、图表表达四个方向形成判断。每项写清“新增了什么、哪里做得好、为什么有价值”，并关联原文位置。

## 判断亮点

**新颖性**放回论文发表时的证据背景判断。选取最相关的既往原始研究，比较人群、问题、干预或对照、测量方法、分析与结论。同年文献比较时核对具体发表日期。明确贡献属于新问题、新方法、新发现，还是对既有证据的扩展。采用成熟方法也可以通过执行质量形成亮点。

**完成质量**关注研究怎样把问题回答得扎实：比较对象是否贴合问题，共同干预怎样安排，关键测量怎样完成，执行与失访如何交代，效应量及其精度怎样呈现，分析与结论怎样衔接。把“随机、多中心、大样本”等标签展开为具体贡献。

**表达质量**包括图表的准确性、清晰度、信息组织和美观。检查坐标与单位、分母、误差线、图例、配色、线型、字体、留白与多面板顺序。好看的图同样可以是文章的优秀之处；说明它怎样帮助读者看懂组间比较、时间变化、机制或研究过程。以实际查看过的原图为依据，把视觉判断记录为汇报者分析。

| 亮点所在 | 正文怎样重点讲 |
|---|---|
| 选题 | 背景讲清已有研究做到了哪里、本文补充什么、为什么这个问题值得研究。背景通常一页；确有独立研究逻辑需要展开时使用第二页。 |
| 方法 | 方法先展示原文流程图，再讲关键设计、操作、对照和分析，以及它们为什么解决了问题。常规步骤简述。 |
| 结论与讨论 | 结果突出关键效应量、时间点与分析人群，讨论展开发现到临床或研究意义的推理，并联系既有证据。 |
| 图表 | 在对应结果页完整展示原图，按面板顺序带听众读图，讲清图中发现；文章亮点页总结其信息组织和视觉表达的长处。 |

选取 1–3 项主要亮点。其他内容按理解研究所需保留，讲述时间体现主次。兼顾文章的实际价值、证据完整性和听众需求。

## 方法亮点的比较基准

常规随机分组、对照条件一致、按患者划分训练集、常规回归和失访说明，归入研究质量与基础方法。方法亮点需要写清：发表时的通行做法、本文具体改动、改动解决的问题，以及原文提供的效果或验证证据。

优先识别新测量方式、新干预设计、算法学习目标的改变，以及有实质贡献的统计分析。统计方法可以是新估计量、新识别策略，或针对本研究难点作出的有效改进；按研究问题说明为何采用、估计什么、依赖什么假设，以及相对常规分析增加了什么信息。方法名称复杂、采用机器学习或使用成熟方法本身属于技术描述。特别出色的执行可作为完成质量亮点，需交代超出通行实践的具体设计与证据。

将方法判断分别归为方法贡献、执行质量或基础做法。主要亮点优先对应有明确比较依据的方法贡献；基础做法简述。算法论文分别评价网络结构、学习目标、验证设计和统计解释，把成熟组件与本文贡献写清楚。方法页用连续段落说明具体步骤和作用，亮点页归纳其贡献。

## 讨论后的独立评价

顺序为：讨论 → 亮点 → 局限 → 感想。正文大标题使用两个字“亮点”和“局限”，小标题给出本页主题。亮点总结具体贡献与优秀之处，局限说明具体问题及其对解释或适用范围的影响。两部分各默认一页，用 2–3 个面向听众的连续段落适度展开。亮点写清具体贡献及支撑它的设计或结果，局限写清问题及其解释后果；正文保留实质信息，讲稿补足分析。主要亮点应已在前面的对应章节充分展开，最后的亮点页承担归纳作用。

局限覆盖最影响理解的事项，例如样本选择、测量与盲法、共同干预、治疗交叉、随访范围和执行一致性。用事实与解释说明影响。原文报告和汇报者分析分别关联证据。

## 内容记录

正式文献汇报使用 `deck.focus_policy: contribution_driven_v1`，并填写 `literature.focus_plan`。旧记录继续兼容；新编排默认启用本策略。功能样张标记 test_fixture。

focus_plan 保存 publication_year、narrative_priority、assessments 和 allocation。assessments 覆盖 question、method、interpretation、visual 四个 domain。每项有独立 id、claim、what_new、what_well、why_it_matters、evidence、slide_ids，以及：

- novelty：new、incremental、established 或 unassessed。
- quality：strong、adequate、mixed 或 unassessed。
- priority：primary、secondary 或 routine。
- comparisons：对照研究的 source_id、year 与具体 difference。新颖性判断关联发表时已有的研究，引用范围对应实际读取内容。

allocation 按稳定页 id 记录 emphasis（core、standard、brief）、talk_time_sec 和 focus_links。编排器把这些字段写入对应页。重点页面与实际亮点关联，讲稿充分展开其价值。时间是演讲规划建议，按使用者的时长调整。

脚本核对来源、时间关系、章节覆盖、页序和重点安排；具体创新程度、优秀之处及审美质量由通读全文、比较研究和查看图表后判断。交付前朗读重点页面与讲稿，核对篇幅和时间是否真正反映所选亮点。

审阅包附带 focus-plan.txt，网页的成品下载菜单提供“讲述重点”，用于查看具体判断依据和逐页时间安排。
