# 汇报结构

按听众、时长和材料组织结构。

| 类型 | 重点 |
|---|---|
| 文献汇报 | 全文标题截图、作者信息、背景、方法、结果、讨论、亮点、局限、感想；见 [生成流程](literature-report.md) |
| 原创研究 | 研究问题、数据与方法、结果、解释、局限 |
| 指南解读 | 适用人群、推荐内容、证据级别、执行条件与例外 |
| 专题综述 | 明确问题、证据分布、相同与冲突的结果、知识缺口 |
| 病例教学 | 去标识病史、关键影像、鉴别与决策、随访及讨论 |
| 答辩 | 问题与贡献、方法、核心结果、可信度和适用范围 |

每页记录要回答的问题；讲稿直接解释图表的关键发现与意义，并衔接下一项内容。生成过程另存于工作记录。来源索引将页面论断关联到具体原文位置。
