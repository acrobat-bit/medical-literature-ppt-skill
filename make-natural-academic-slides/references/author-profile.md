# 作者介绍与著作检索

## 选择对象

第二页使用大标题“作者”和小标题“简介”，只展示一人。默认从论文作者名单中选择署名列首位的第一作者；共同第一作者按原文标记其角色。

检索对象是除当前汇报论文外的其他著作。第一作者有可确认归属的发表文章时，介绍第一作者。若数据库检索与机构官网、ORCID 或期刊网站等补充检索均未找到可确认条目，改为介绍原文通讯作者。多位通讯作者按原文通信联系人顺序选择有可确认发表的对象。保留实际查询来源、检索式、日期及选择依据。

将“本次检索未找到可确认条目”记录为检索结果。作者的学术履历按查到的原始材料描述。

## 检索与研究领域归纳

1. 从当前论文提取英文全名、机构、共同作者和 ORCID。中文姓名按机构官网核对。
2. 用可用文献检索工具查询 PubMed、期刊原文、机构研究档案或 ORCID。先检索姓名与机构，再结合共同作者、主题及姓名变体补充。
3. 逐篇检查姓名、作者顺序、机构和至少一项匹配线索，如 ORCID 或合作者。优先保存论文原文或 PubMed 的 DOI、PMID、期刊和年份。按正式刊期列年份，在线发表日期单独记录。
   检索命中数与已确认归属的篇数分别记录。作者页只使用已完成归属核对的条目。
4. 从已核对论文的题名与摘要提取研究对象、技术和结局。将相近主题概括为 1–3 个研究领域，并逐项关联支撑论文。页面标明“据已发表论文归纳”。
5. 页面选择 1–3 篇能说明研究领域的发表，将研究领域与代表性发表写成连续段落，保留简短中文题名、年份、期刊和作者角色。完整英文题名、DOI/PMID、作者归属依据与其他核对条目放入证据面板。讲稿直接介绍作者的工作及其与本文的联系。

任职与照片取自机构公开资料，研究领域由已发表文章支持。保留第一作者、共同第一作者、通讯作者、共同作者等实际角色。

## 输入字段

在 `literature` 中填写：

| 字段 | 内容 |
|---|---|
| first_author_name | 当前论文署名列首位作者的英文全名 |
| corresponding_author_names | 当前论文通讯作者英文全名，按原文顺序 |
| author_search | 实际检索记录列表，每项包含 author_name、source、query、searched_at、status（completed） |
| author_candidates | 第一作者的查询结果，以及需要时查询的通讯作者资料 |

候选作者使用通用作者字段，并增加：

| 字段 | 内容 |
|---|---|
| publication_name | 与作者选择记录对应的英文全名 |
| publications | 已确认的其他发表列表 |
| research_areas | 1–3 项，包含 label 与 publication_ids |

每篇 `publications` 记录：

- `source_id`：在 sources 中关联论文原始记录，包含 DOI/PMID 和来源链接。
- `title`、`display_title`：完整原文题名、用于页面的简短中文题名。
- `year`、`journal`：正式刊期年份（整数）、期刊缩写。
- `author_name`、`author_role`：所选作者的英文全名与本篇发表角色。
- `status`：已完成归属核对时为 verified。
- `identity_evidence`：至少两项归属依据，具体记录署名、机构、ORCID 或共同作者。
- `on_slide`：可选，默认 true；作者页展示最多 3 篇，其他已核对文章设为 false，仍进入证据面板。

`research_areas[].publication_ids` 关联上述发表的 source_id。原文全文与摘要支持主题归纳，任职头衔另按机构资料填写。

`scripts/literature.py` 自动应用 `first_author_then_corresponding` 策略，选择一人写入 authors，并记录 author_selection。早期内容记录按其已保存的结构校验；新编排使用上述作者流程。

## 验收

检查一位作者、真实头像、任职、本文角色、研究领域及 1–3 篇相关发表。将姓名、论文和机构逐项对应，核对研究领域的来源关联。对第一作者有著作、第一作者未检出其他著作后切换通讯作者、同名归属不一致等情形，运行 `tests/test_author_profile.py` 验证选择和校验行为。
